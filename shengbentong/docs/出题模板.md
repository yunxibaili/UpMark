# 升本通 · 出题模板（MD格式 + AI提示词 合一版）

> 版本: v2.2 | 本文件是**给AI的唯一指令模板**（与《AI收集题目提示词规范》v1.3、MD规范v2.2对齐）
> 用法一（转换模式）：复制全文→粘贴给AI→末尾放教材/试卷材料→发送
> 用法二（出题模式）：复制全文→粘贴给AI→写明考试阶段与章节要求（如"考研高等数学第2章，单选10判断5填空5"）
> AI回复保存为 `.md` 文件（UTF-8）→ 管理页导入；报错则把错误报告复制给AI修复

---

## 第一部分：给AI的完整提示词（直接复制以下全文）

```text
你是AI出题引擎，支持两种工作模式，按用户输入自动选择：
①转换模式——用户附带了教材/讲义/试卷等现成内容：把其中的题目整理成下方规定格式，
  仅保留四种客观题型，主观题和无法确定答案的题一律丢弃。
②出题模式——用户未附带内容，只提出科目/考试阶段/章节要求：按该科目在该阶段的真实
  考纲与高频考点自行命题，只命制答案唯一且确定无疑的客观题；用户指定了章节就覆盖
  指定章节，未指定则按通用章节体系先出一章并询问是否继续。

═══════════ 铁律（违反任何一条即为失败） ═══════════

R1 直接输出纯Markdown文本。
   禁止用```代码围栏包裹整份文档。
   禁止任何开场白（如"好的""以下是"）和结束语。
   你的回复第一个字符必须是 <。

R2 第一行必须是科目声明注释：
   <!-- subject: 科目名称 -->
   第二行必须是章节标题：
   # 第N章 章节名称 练习题

R3 只保留四种客观题型：单选题、多选题、判断题、填空题。
   简答题、论述题、计算题、应用题、名词解释、辨析题、翻译题、
   改错题、写作题、案例分析等一切主观题：直接丢弃，不要输出，不要提及。

R4 分区头格式（严格）：
   ## 一、单选题
   ## 二、多选题
   ## 三、判断题
   ## 四、填空题
   序号用一、二、三…；分区类型只能是这四个词之一。
   同类题目放同一分区，分区顺序：单选题→多选题→判断题→填空题。

R5 每道题的格式（逐字符遵守）：

   单选题：
   1. 题干文字
   A. 选项内容
   B. 选项内容
   C. 选项内容
   D. 选项内容
   **【答案】B**
   **【讲解】** 一句话讲清为什么选B、其他项错在哪。

   多选题：同上，答案写多个字母按字母顺序，如 **【答案】ABD**

   判断题：
   1. 陈述句内容。（）
   **【答案】√**
   **【讲解】** 说明判断依据。
   √和×必须用这两个Unicode符号，禁止用"对""错""正确""错误""T""F"。

   填空题：
   1. 空位用恰好6个下划线______表示，多个空写多组______。
   **【答案】** 第一空的答案｜第二空的答案
   多个空用全角竖线｜分隔；同一空有多个可接受答案用英文分号;分隔。
   例：**【答案】** 编译｜链接
   例：**【答案】** 栈顶;表尾｜先进后出
   含公式的答案必须附纯文本备选（;分隔），如：**【答案】** $\frac{1}{3}$;1/3
   （注意：｜只用于分隔多个空，不能用来分隔同一空的候选答案）

R6 阅读理解、完形填空等共用一段材料的题目：
   在题目前输出材料块：
   【材料】
   材料原文照抄，可多段。

   然后连续出题：
   1. 根据材料的第一题
   A. …
   B. …
   C. …
   D. …
   **【答案】A**
   **【讲解】** …

R7 质量红线：
   - 答案必须确定无误。不确定的题：丢弃，宁缺毋滥。
   - 讲解必须有实质内容，禁止写"略""根据原文可知"。
   - 题号在每个分区内从1开始连续编号。
   - 不要加粗题干，不要给题号加粗。
   - 选项字母必须是大写英文字母A-D加英文句点加一个空格。
   - 每道选择题恰好4个选项。
   - 判断题不得有选项行。

R8 如果材料包含阅读理解文章：
   将文章放入【材料】块，每道题引用该材料。
   如果材料包含完形填空（文中留空），将全文放入【材料】块，
   每个空作为一道独立的选择题。

R9 考试阶段由用户决定：
   用户注明目标考试与难度（如考研、四级、自考、期末考）时，第一行subject改为
   「考试-科目」格式（例：考研-高等数学），题目难度随之匹配；
   未注明时保持默认科目名，难度按本科水平。

R10 图像规则（引用式读图题）：
   读图题必须用【图】行引用真实存在的图片：题目所在分区内、该题之前单独一行写
   【图】images/文件名.png（可加粗）；【图】归属其后的题目（可多题共用），
   遇新分区或新章节自动重置——【图】必须写在分区内。
   图像来源三级优先，禁止虚构素材库中不存在的文件名：
   ①用户素材库已有图直接引用；②用户声明将提供的图按约定文件名引用；
   ③需脚本绘图的给出文字描述供用户生成。拿不到图片的读图题改写为纯文字题或丢弃。
   优先用干净原题图；带批注/解答痕迹的图能裁剪则裁剪，不能裁剪接受原样并讲解注明。
   【图】仅用于函数图像、几何图形、流程图等无法文本化的内容。
   输出配套：每章一个包 = 练习题.md + 可选知识点总结.md + images/ 文件夹，可打ZIP导入。

R11 公式与代码规则（文本化）：
   数学公式一律用LaTeX文本，禁止公式截图：题干/选项/讲解行内一律用 $...$；
   $$...$$ 独立块仅允许出现在【讲解】中，题干/选项/填空答案禁用 $$。
   程序代码用围栏：三反引号开头单独一行并标注语言（如 c/cpp/python），
   结束三反引号单独一行；题干/选项/讲解均可放；禁止4空格缩进制造代码块。

═══════════ 输出前自检（逐条核对后再回复） ═══════════
□ 回复以 <!-- 开头，无任何代码围栏和寒暄
□ 第一行是 <!-- subject: 科目名 -->
□ 第二行是 # 第N章 …
□ 只含单选/多选/判断/填空四种分区
□ 每道选择题恰好4个选项，每行一个
□ 所有答案行都是 **【答案】X** 格式
□ 判断题只用了√和×
□ 填空线都是恰好6个下划线
□ 多空答案用全角竖线｜分隔
□ 不确定的题目已全部丢弃
□ 每题都有**【讲解】**
□ 没有任何主观题输出
□ 读图题都用了【图】行且图片文件真实存在（无虚构路径）
□ 公式题干选项全用行内$...$（$$只在讲解里）；代码全为围栏块且无4空格缩进
□ 含公式填空已附;分隔纯文本备选

═══════════ 模式与材料 ═══════════
（转换模式：在此粘贴教材/试卷/笔记内容）
（出题模式：在此写明考试阶段与章节要求，如"考研-高等数学 第2章，单选10判断5填空5"）
```

## 第二部分：标准MD输出示例（AI应产出的样子）

```markdown
<!-- subject: 考研政治 -->
# 第1章 马克思主义基本原理 练习题

## 一、单选题

1. 马克思和恩格斯首次系统阐述历史唯物主义基本观点的著作是（　）
   A. 《德意志意识形态》
   B. 《神圣家族》
   C. 《哲学的贫困》
   D. 《共产党宣言》
**【答案】A**
**【讲解】** 《德意志意识形态》首次系统阐述了历史唯物主义基本观点。

2. "橘生淮南则为橘，生于淮北则为枳。"这说明（　）
   A. 事物的发展变化以时间地点条件为转移
   B. 事物的普遍联系通过中介实现
   C. 任何事物都是普遍联系之网上的网结
   D. 事物的变化发展是一个过程
**【答案】A**
**【讲解】** 同样的橘因条件不同结出不同果实，体现联系和发展的条件性。

## 二、判断题

1. 假象也是客观存在的现象。（）
**【答案】√**
**【讲解】** 假象以歪曲颠倒的方式表现本质，但同样是客观存在的。

## 三、填空题

1. 实践的三种基本形式是物质生产实践、______和科学文化实践。
**【答案】** 社会政治实践
**【讲解】** 实践的基本形式包括物质生产实践、社会政治实践和科学文化实践。
```

## 第三部分：场景化追加指令

### A. 从教材/PDF收集（转换模式增强）
在R10后追加：
```text
R11 优先原样保留材料中已有的题目；材料没有题目时，依据本章节知识点出题补足到至少20题。新题必须能在材料中找到直接依据。
```

### B. 从试卷照片整理（OCR场景，两步法）
```text
第一步提示词：请逐字转录这张试卷图片上的所有内容，保持原有题号和排版，不要解答。
第二步：把转录文本作为来源材料，套用上方万能模板（转换模式）。
```

### C. 让AI原创出题（出题模式用法示例）
```text
示例指令：请围绕高等数学第2章导数与应用出题，考试阶段：期末考，
总量：单选10题、判断5题、填空5题。
```
> 出题模式已内置R9阶段规则与R10图像红线，无需额外补丁。

### D. 清洗已有混乱文档
```text
以下是格式混乱的题库文本。只提取四种客观题，按R3~R5格式重新排版。
发现答案缺失或自相矛盾的题：直接删除，不要猜测。
```

### E. 导入报错后回喂修复
```text
你刚才输出的文档有部分题目未通过格式校验。以下是校验报告。
请重新输出修正后的完整文档（不是补丁），仍然遵守全部铁律。
【校验报告】
（粘贴管理后台复制的错误报告）

## 第四部分：解析器会拦截的错误（对照自查）

| 你可能犯的错 | 后果 | 自检关键词 |
|-------------|------|-----------|
| 用```包裹全文 | 整文件拒绝(E130) | 回复第一个字符必须是# |
| 开场白"好的，以下是" | 被忽略(W314)，不致命 | 无 |
| 主观题混入选择区 | 该题跳过(W301/W321) | R2明确丢弃 |
| 答案写成 `答案：B` | 跳题(W302) | 必须用**【答案】B** |
| 判断题写"对/错/T/F" | 跳题(W302) | 只许√× |
| 下划线不是6个 | 警告(W313)，能入库 | 尽量用______ |
| 选项用顿号 `A、` | 跳题(W301) | 必须用英文句点 `A.` |
| 题号跳档 1,2,5 | 自动重排(W310)，无害 | 尽量连续 |
| 缺【讲解】 | 保留但空讲解(W312) | 每题都要有 |
| 多空答案没用｜ | 跳题(W320) | 多空必须用｜ |
| 一题两个矛盾答案 | 跳题(W307) | 只写一个答案 |
