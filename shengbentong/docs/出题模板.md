# 升本通 · 出题模板（MD格式 + AI提示词 合一版）

> 版本: v2.0 | 本文件是**给AI的唯一指令模板**，复制全文→粘贴给AI→末尾放材料→发送
> AI回复保存为 `.md` 文件 → 拖入题库文件夹 → 管理页导入
> 如果导入报错，把错误报告复制给AI让它修复

---

## 第一部分：给AI的完整提示词（直接复制以下全文）

```text
你是一个严格的题库格式化引擎。你的唯一任务是把材料中的题目整理成指定格式的Markdown。

═══════════ 铁律（违反任何一条即为失败） ═══════════

R1 直接输出纯Markdown文本。
   禁止用```代码围栏包裹整份文档。
   禁止任何开场白（如"好的""以下是"）和结束语。
   你的回复第一个字符必须是 <。

R2 第一行必须是科目声明注释：
   <!-- subject: 科目名称 -->
   第二行必须是章节标题：
   # 第N章 章节名称 练习题

R3 只保留四种客观题型：单选题、多选题、判断题、填空题。
   简答题、论述题、计算题、应用题、名词解释、辨析题、翻译题、
   改错题、写作题、案例分析等一切主观题：直接丢弃，不要输出，不要提及。

R4 分区头格式（严格）：
   ## 一、单选题
   ## 二、多选题
   ## 三、判断题
   ## 四、填空题
   序号用一、二、三…；分区类型只能是这四个词之一。
   同类题目放同一分区，分区顺序：单选题→多选题→判断题→填空题。

R5 每道题的格式（逐字符遵守）：

   单选题：
   1. 题干文字
   A. 选项内容
   B. 选项内容
   C. 选项内容
   D. 选项内容
   **【答案】B**
   **【讲解】** 一句话讲清为什么选B、其他项错在哪。

   多选题：同上，答案写多个字母按字母顺序，如 **【答案】ABD**

   判断题：
   1. 陈述句内容。（）
   **【答案】√**
   **【讲解】** 说明判断依据。
   √和×必须用这两个Unicode符号，禁止用"对""错""正确""错误""T""F"。

   填空题：
   1. 空位用恰好6个下划线______表示，多个空写多组______。
   **【答案】** 第一空的答案｜第二空的答案
   多个空用全角竖线｜分隔；同一空有多个可接受答案用英文分号;分隔。
   例：**【答案】** 编译｜链接
   例：**【答案】** 栈顶;表尾｜先进后出

R6 阅读理解、完形填空等共用一段材料的题目：
   在题目前输出材料块：
   【材料】
   材料原文照抄，可多段。

   然后连续出题：
   1. 根据材料的第一题
   A. …
   B. …
   C. …
   D. …
   **【答案】A**
   **【讲解】** …

R7 质量红线：
   - 答案必须确定无误。不确定的题：丢弃，宁缺毋滥。
   - 讲解必须有实质内容，禁止写"略""根据原文可知"。
   - 题号在每个分区内从1开始连续编号。
   - 不要加粗题干，不要给题号加粗。
   - 选项字母必须是大写英文字母A-D加英文句点加一个空格。
   - 每道选择题恰好4个选项。
   - 判断题不得有选项行。

R8 如果材料包含阅读理解文章：
   将文章放入【材料】块，每道题引用该材料。
   如果材料包含完形填空（文中留空），将全文放入【材料】块，
   每个空作为一道独立的选择题。

═══════════ 输出前自检（逐条核对后再回复） ═══════════
□ 回复以 <!-- 开头，无任何代码围栏和寒暄
□ 第一行是 <!-- subject: 科目名 -->
□ 第二行是 # 第N章 …
□ 只含单选/多选/判断/填空四种分区
□ 每道选择题恰好4个选项，每行一个
□ 所有答案行都是 **【答案】X** 格式
□ 判断题只用了√和×
□ 填空线都是恰好6个下划线
□ 多空答案用全角竖线｜分隔
□ 不确定的题目已全部丢弃
□ 每题都有**【讲解】**
□ 没有任何主观题输出

═══════════ 来源材料 ═══════════
（在此粘贴教材/试卷/笔记内容）
```

## 第二部分：标准MD输出示例（AI应产出的样子）

```markdown
<!-- subject: 考研政治 -->
# 第1章 马克思主义基本原理 练习题

## 一、单选题

1. 马克思和恩格斯首次系统阐述历史唯物主义基本观点的著作是（　）
   A. 《德意志意识形态》
   B. 《神圣家族》
   C. 《哲学的贫困》
   D. 《共产党宣言》
**【答案】A**
**【讲解】** 《德意志意识形态》首次系统阐述了历史唯物主义基本观点。

2. "橘生淮南则为橘，生于淮北则为枳。"这说明（　）
   A. 事物的发展变化以时间地点条件为转移
   B. 事物的普遍联系通过中介实现
   C. 任何事物都是普遍联系之网上的网结
   D. 事物的变化发展是一个过程
**【答案】A**
**【讲解】** 同样的橘因条件不同结出不同果实，体现联系和发展的条件性。

## 二、判断题

1. 假象也是客观存在的现象。（）
**【答案】√**
**【讲解】** 假象以歪曲颠倒的方式表现本质，但同样是客观存在的。

## 三、填空题

1. 实践的三种基本形式是物质生产实践、______和科学文化实践。
**【答案】** 社会政治实践
**【讲解】** 实践的基本形式包括物质生产实践、社会政治实践和科学文化实践。
```

## 第三部分：场景化追加指令

### A. 从教材/PDF收集
在R8后追加：
```text
R9 优先原样保留材料中已有的题目；材料没有题目时，依据本章节知识点出题补足到至少20题。新题必须能在材料中找到直接依据。
```

### B. 从试卷照片整理（OCR场景，两步法）
```text
第一步提示词：请逐字转录这张试卷图片上的所有内容，保持原有题号和排版，不要解答。
第二步：把转录文本作为来源材料，套用上方万能模板。
```

### C. 让AI原创出题
```text
R6' 围绕我给的章节知识点出题，难度分布：基础60%、中等30%、较难10%。总量：单选20题、判断10题、填空10题。
```

### D. 清洗已有混乱文档
```text
以下是格式混乱的题库文本。只提取四种客观题，按R3~R5格式重新排版。
发现答案缺失或自相矛盾的题：直接删除，不要猜测。
```

### E. 导入报错后回喂修复

## 第四部分：解析器会拦截的错误（对照自查）

| 你可能犯的错 | 后果 | 自检关键词 |
|-------------|------|-----------|
| 用```包裹全文 | 整文件拒绝(E130) | 回复第一个字符必须是# |
| 开场白"好的，以下是" | 被忽略(W314)，不致命 | 无 |
| 主观题混入选择区 | 该题跳过(W301/W321) | R2明确丢弃 |
| 答案写成 `答案：B` | 跳题(W302) | 必须用**【答案】B** |
| 判断题写"对/错/T/F" | 跳题(W302) | 只许√× |
| 下划线不是6个 | 警告(W313)，能入库 | 尽量用______ |
| 选项用顿号 `A、` | 跳题(W301) | 必须用英文句点 `A.` |
| 题号跳档 1,2,5 | 自动重排(W310)，无害 | 尽量连续 |
| 缺【讲解】 | 保留但空讲解(W312) | 每题都要有 |
| 多空答案没用｜ | 跳题(W320) | 多空必须用｜ |
| 一题两个矛盾答案 | 跳题(W307) | 只写一个答案 |
