> AI收集（提示词规范）──→ 生成尽量合规的MD ──→ 本规范解析（最后防线）

## 一、适用范围与题型总纲

面向**任意考试科目**（计算机/英语/政治/毛概/数学/语文/专业课……）。语法与科目无关。

基于对高考、考研、专升本（广东/福建/四川/山东/河北等省）、成人高考试卷的题型普查：

### 1.1 解析支持的题型（白名单）

| 分区头关键词 | 归一化题型 | 别名（自动识别） |
|--------------|-----------|------------------|
| `单选题` | 单选 | 单项选择题、选择题 |
| `多选题` | 多选 | 多项选择题 |
| `判断题` | 判断 | 判断正误、判断正误题 |
| `填空题` | 填空 | 填空 |

覆盖场景：普通选择、完形填空（AI转为共享材料的选择题）、语法填空（英语，空位带提示词）、名句默写（语文）、数学/专业课数值填空。

### 1.2 自动跳过的题型（非白名单一律跳过分区）

简答题、论述题、问答题、计算题、应用题、证明题、解答题、综合题、综合应用题、分析题、材料分析题、案例分析题、案例题、材料题、辨析题、名词解释(题)、词语解释题、释词题、翻译题、英译汉、汉译英、文言文翻译、改错题、短文改错、写作题、作文、短文写作、补全对话、阅读理解、阅读分析题、古诗词鉴赏、作品赏析题、默写题、名句默写题、操作题、设计题、识图题、七选五、其他任何未列出的类型。

### 1.3 容错总策略（v2.0 核心）

| 层级 | 异常 | 处理 |
|------|------|------|
| 文件级 | 编码错误/BOM、代码围栏不配对、最终0题可用 | **拒绝整个文件** |
| 分区级 | 题型不在白名单 | **跳过整区**（W205），区内不做校验 |
| 题目级 | 缺选项/缺答案/答案非法/无空位等 | **跳过该题**（W3xx），继续下一题 |
| 字段级 | 题号断档、混用样式、缺讲解等 | **自动修复并保留**（W3xx 警告） |

> 原则：**能救一道是一道，但绝不静默丢弃**——每一道被跳过的题都必须出现在导入报告中，附文件、行号、原因码。

## 二、全局规则

| 编号 | 规则 |
|------|------|
| G1 | UTF-8 无 BOM（否则 E100 拒绝文件） |
| G2 | LF 或 CRLF 均可，解析前归一化 |
| G3 | 一个 md 文件 = 一个章节 或 一份试卷 |
| G4 | 正文缩进只用空格；Tab 仅限代码块内 |
| G5 | 行内支持粗体 `**x**`、行内代码 `` `x` `` 与LaTeX行内公式 `$...$`（均为透传文本，解析器不解析其语义）；其余行内语法在题目字段中禁止、在材料中忽略（v2.2） |
| G6 | 首个 H1 之前的非空行：若是 HTML 注释则忽略，否则警告 W314 后忽略（容忍 AI 的"好的，以下是…"开场白） |
| G7 | ``` 围栏内一切内容不参与词法解析；围栏必须配对（E122 否则拒文件）。围栏块按出现位置路由：材料内→并入材料；题干后→并入题干；选项后→并入末选项内容；答案/讲解后→并入讲解（v2.2明确） |
| G8 | 【图】引用的图像文件与 md 同库存放（相对路径）；导入时由服务端拷入静态目录，md 内不写绝对路径（v2.1） |
| G9 | `$$...$$` 独立公式块为透传文本：整块原样并入所在字段（题干/讲解），块内容不参与词法解析与题目边界判定（v2.2） |

## 三、文件类型与命名

| 类型 | 文件名 | 必需性 | H1 |
|------|--------|--------|-----|
| 练习文件 | `练习题.md` | 科目必需 | `# 第N章 名称[ 练习题]` |
| 知识点文件 | `知识点总结.md` | 可选 | `# 第N章 名称[ 知识点总结]` |
| 试卷文件 | 任意 | 可选 | `# 卷名`，允许连续两行H1封面 |

- 章节号 N：阿拉伯（第1章）或中文（第一章）；科目内不得重复（重复时后者改名追加 `-2` 并告警 W317）
- **缺 H1 不再致命**：以子目录名兜底为章节标题，警告 W315
- 目录结构 = 科目：`某科目/01-章节名/{练习题.md,知识点总结.md,images/}`
- 图像推荐集中存放于章节子目录的 `images/` 下（如 `images/parabola.png`），路径写法不限层级，但必须是**相对 md 文件的相对路径**

## 四、分区头

```
## <中文序号>、<分区类型><可选注记>
```

- 序号 `一`~`二十`：**不再强制连续**。异常时警告 W316，按出现顺序处理
- 类型匹配规则：去掉注记后，取「、」后的文字做前缀匹配白名单及别名表（如 `单项选择题（本大题共20小题…）` → 单选）
- 白名单外的一切类型 → 跳过整区 W205，记录起止行号
- 同类型分区可多次出现（如`六、单选题（新增）`），解析器顺序合并
- **分区头重置共享状态**：进入新分区时，当前【材料】与当前【图】一并清空（v2.1 明确）

## 五、【材料】块（v2.0 新增）

用途：阅读理解、完形填空、材料题的**共享题干**。

```markdown
【材料】
Passage One
Last Friday, our school held ...（可多段，空行不断开）

21. What did the writer do last Friday?
   A. ...
```

规则：
- M1: 以行首 `【材料】` 开启（允许写成 `**【材料】**`），其后所有行归入材料
- M2: 终止条件＝下一个题干起始行 / 下一个 `## ` 分区头 / 下一个 `【材料】` / 下一个 `【图】` / 文件尾
- M3: 材料归属于其后的题目；再次遇到 `【材料】` 时替换当前材料
- M4: 材料内允许任意文本、代码块；不做词法校验
- M5: 无材料归属的题目照常独立成立（材料字段为 null）

---

## 六、【图】图像标记（v2.1 新增）

用途：读图题、函数图像题等的**题目配图**。图像不内嵌于 md，只写相对路径引用。

```markdown
## 一、单选题

【图】images/parabola.png

1. 图示函数图像的开口方向是？
A. 向上
B. 向下
C. 向左
D. 向右
**【答案】A**
```

规则：
- P1: 以行首 `【图】<相对路径>` 标记（允许写成 `**【图】<相对路径>**` 加粗形态）；路径为 `【图】` 后到行尾的非空白文本，不允许引号包裹之外的修饰
- P2: **语义同【材料】**——归属于其后出现的题目；再次出现 `【图】` 时替换当前图像；可与 `【材料】` 共存（互不覆盖，一题同时携带 material 与 image）
- P3: `【图】` 行本身终止当前题目与当前材料块（同题干起始行的边界效果）
- P4: 进入新分区头时当前图像清空——**【图】必须写在分区内**，写在分区头之前会被重置丢弃且无警告（与材料同理）
- P5: 空路径（`【图】` 后无内容）→ 警告 W322，该行忽略，不影响当前图像
- P6: 解析器只保存相对路径字符串，不做文件检查；**导入阶段**由服务端按 md 所在目录解析相对路径：
  - 文件存在 → 拷贝入服务端静态目录 `/static/images/`（sha1 摘要命名防撞名；同名源文件内容更新时覆盖），题目 image 字段存 `/static/images/<编码后文件名>` URL
  - 文件不存在 → 警告 W323，image 置 null，**题目照常保留，不阻断导入**
- P7: 图像格式以扩展名识别（png/jpg/jpeg/gif/webp 等）；无扩展名时按 `.png` 处理

## 七、题目结构

### 7.1 题干起始（三种合法样式，区内可混用→W311）

| 样式 | 语法 | 正则 |
|------|------|------|
| A 列表式 | `数字. 内容` | `^(\d{1,3})\. ` |
| B 标题式 | `### 数字. 内容` | `^### (\d{1,3})\. ` |
| C 标签式 | `**题目数字**[ [难度：★+]]` | `^\*\*题目(\d{1,3})\*\*( \[难度:[★]{1,3}\])?$` |

- 题号断档/重复**不再致命**：警告 W310，全部按出现顺序重排全局序号

### 7.2 选项行

- 单行一项：`字母. 内容`，前导空格 0~8 个
- 单行多项：`A. xx　　B. yy`（两个及以上全角空格分隔）
- 单选：恰好4项 A–D（少于2项→W301跳过该题；2~3项或5~6项→W305跳过）
  > 兼容现实试卷中3选项/判断式选择？否——统一要求4项，AI提示词负责源头保证；不足即跳过上报
- 多选：4项 A–D；答案为2个及以上字母
- 字母必须大写 ASCII 且连续

### 7.3 答案行

```
**【答案】X**          ← 加粗（推荐）
**【答案】** X         ← 加粗空体+同行内容
【答案】X              ← 仅样式C分区内合法，样式A/B区中出现也接受（W318）
```

| 题型 | 合法值 |
|------|--------|
| 单选 | 单字符 ∈ ABCD |
| 多选 | 2~4字符 ∈ ABCD，升序无重复 |
| 判断 | √ (U+221A) 或 × (U+00D7)；`对/错/T/F/正确/错误/true/false` 一律非法→跳过W302 |
| 填空 | 非空文本；多空用 `｜` 分段；同一空多个可接受答案用 `;` 分隔 |

- 缺答案行 / 值非法 → **跳过该题 W302**
- 同题多个答案行：值相同→去重+警告；值不同→跳过 W307

### 7.4 讲解行

```
**【讲解】** 内容…
【讲解】内容…            （样式C区常见，A/B区出现亦接受 W318）
```

- **缺讲解不再跳题**：保留题目，讲解置空，警告 W312
- 讲解可跨行直到题目边界；支持列表/代码块

### 7.5 填空位标记与答案分隔

- 标准：恰好 6 个半角下划线 `______`
- 其他 ≥3 连续下划线：同样识别，警告 W313
- 填空题题干中一个空位都没有 → 跳过 W304
- 多空答案标准分隔符：中文竖线 `｜`；同一空的备选用分号 `;`
- **旧版兼容（W319）**：多空(≥2)答案未用`｜`时，依次尝试 `、` `，` `,` `；` 拆分，
  仅当段数恰等于空位数时采用并告警；单空永不触发（避免与备选`;`冲突）
- 兼容后仍段数不符 → 跳过该题 W320

### 7.5a 行内选项（真题卷形态）与完形填空空题干

- **行内选项**：题干与选项同行（`1. 题干 A. x　　B. y　　C. z　　D. w`）合法；
  仅当字母链A→B→C→D完整时自动拆分，否则整体视为题干交由下游规则处置
- **完形填空空题干**：存在【材料】且选项完整时，允许题干为空
  （如`1. A. x B. y C. z D. w`），App按"材料第N空"呈现；无材料时空题干仍跳过W303

### 7.6 题目边界

从题干起始行开始，到下一个「题干起始 / `##` / `【材料】` / `【图】` / 文件尾」结束。`---` 忽略。

## 八、各题型字段清单

| 题型 | 必需 | 可选 | 缺失后果 |
|------|------|------|----------|
| 单选 | 题干、4选项、答案 | 材料、图像、难度、注记分值 | 缺任一必需项→跳题 |
| 多选 | 同上 | 同上 | 同上 |
| 判断 | 题干、答案√× | 材料、图像、难度 | 出现选项行→跳题 W306 |
| 填空 | 题干(含≥1空位)、答案 | 提示词如 `(be)` 属于题干一部分 | 无空位→跳题 W304 |

英语语法填空示例（合法）：题干 `She ______ (go) to school every day.` 答案 `goes`

## 九、校验码总表

### 致命（拒文件）
| 码 | 条件 |
|----|------|
| E100 | 非 UTF-8 或含 BOM |
| E122 | 代码围栏不配对 |
| E130 | 全文件解析完成后可用题数为 0 |

### 分区跳过
| 码 | 条件 |
|----|------|
| W205 | 非白名单题型分区，整区跳过（记录起止行） |

### 题目跳过（继续解析后续题目）
| 码 | 条件 |
|----|------|
| W301 | 选择题可识别选项 < 2 |
| W302 | 缺答案行或答案值非法 |
| W303 | 题干为空 |
| W304 | 填空题无空位标记 |
| W305 | 选项字母不连续或数目不在 4 |
| W306 | 判断题出现选项行 |
| W307 | 多答案行且值互相矛盾 |

### 字段修复警告（题目保留）
| 码 | 条件 |
|----|------|
| W310 | 题号断档/重复（自动重排） |
| W311 | 区内混用 A/B/C 样式 |
| W312 | 缺讲解行（讲解置空） |
| W313 | 非标准下划线长度 |
| W314 | 游离文本忽略（含AI开场白） |
| W315 | 缺 H1，用目录名兜底 |
| W316 | 分区序号不连续/重复 |
| W317 | 章节号冲突，自动改名 |
| W318 | 非加粗答案/讲解行出现在 A/B 样式区（已接受） |
| W203 | 尾部斜体说明忽略 |
| W322 | 【图】行缺少图像相对路径，该行忽略（v2.1） |
| W323 | 【图】引用的图像文件不存在，image 置 null，题目保留（v2.1，导入阶段检测，报告中 line=0） |

## 十二、与 v2.0 的差异速览

| 项 | v2.0 | v2.1 |
|----|------|------|
| 题目配图 | 无（提示词禁止读图题） | **新增【图】标记**：相对路径引用，语义同【材料】（归属其后题目、随分区重置、可加粗） |
