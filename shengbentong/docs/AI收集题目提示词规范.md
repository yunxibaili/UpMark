# 升本通 AI 收集题目提示词规范 v1.1

> 配套：《MD格式规范v2.1.md》（解析层最后防线）
> 本文档定位：**第一道防线** —— 让 ChatGPT / DeepSeek / Kimi / Claude 等AI在收集整理题目时，
> 直接输出符合解析规范的 MD 文档，从源头减少差错。

```
防线模型：
┌────────────────┐      ┌──────────────┐      ┌──────────────────┐
│ 提示词规范(本文) │ ──→  │ AI 生成 MD    │ ──→  │ 解析规范v2.1导入   │
│ 约束AI的输出格式 │      │ 残留少量差错   │      │ 坏题跳过→报告→回喂 │
└────────────────┘      └──────────────┘      └──────────────────┘
   第一道防线                正常损耗              第二道防线(兜底)
```

## 一、万能提示词模板（直接复制使用）

> 使用方法：复制下方代码块内全部文字 → 粘贴给任意AI → 在末尾【来源材料】处放入你的教材/试卷/资料内容 → 发送。
> AI 回复后：新建 `.md` 文件，把回复**全文**粘贴进去，按 `第N章_练习.md` 命名，拖入科目文件夹即可导入。

```text
你是一个严格的题库格式化引擎。你的唯一任务是把我提供的材料中的题目整理成指定格式的Markdown文档。

═══════════ 铁律（违反任何一条即为失败） ═══════════

R1 直接输出纯Markdown文本。禁止用```代码围栏包裹整份文档，禁止任何开场白（如"好的""以下是"）、结束语、解释说明。你的回复第一个字符必须是#。

R2 只保留四种客观题型：单选题、多选题、判断题、填空题。
   简答题、论述题、计算题、应用题、名词解释、辨析题、翻译题、改错题、写作题、案例分析等一切主观题：直接丢弃，不要输出，不要提及。

R3 文档结构必须是：
   第一行：# 第N章 章节名称 练习题
   分区头：## 一、单选题 （序号用一、二、三…；分区类型只能是这四个词之一：单选题/多选题/判断题/填空题）
   同类题目放同一分区，分区顺序：单选题 → 多选题 → 判断题 → 填空题。

R4 每道题的格式（逐字符遵守）：
   单选题：
   1. 题干文字
   A. 选项内容
   B. 选项内容
   C. 选项内容
   D. 选项内容
   **【答案】B**
   **【讲解】** 一句话讲清为什么选B、其他项错在哪。

   多选题：同上，答案写多个字母且按字母顺序，如 **【答案】ABD**

   判断题：
   1. 陈述句内容。（）
   **【答案】√**
   **【讲解】** 说明判断依据。√和×必须用这两个符号，禁止用"对""错""正确""错误"。

   填空题：
   1. 空位用恰好6个下划线表示______，多个空就写多组______。
   **【答案】** 第一个空的答案｜第二个空的答案
   多个空用全角竖线｜分隔；同一空有多个可接受答案用英文分号;分隔，如：栈顶;表尾｜先进后出

R5 阅读理解、完形填空这类共用一段材料的题：
   先写材料块，再连续出题：
   【材料】
   材料原文照抄，可多段。
   21. 根据材料的第1题
   A. …
   B. …
   C. …
   D. …
   **【答案】A**
   **【讲解】** …

R5a 读图题（v1.1 新增，可选）：
   只允许"引用式"读图题——题目所在分区内、该题之前单独一行写【图】+相对路径：
   【图】images/fig1.png
   1. 图示函数图像的开口方向是？
   A. …
   B. …
   C. …
   D. …
   **【答案】A**
   **【讲解】** …
   铁律：只能引用用户确认会提供且已约定文件名的图片（图片由用户存入章节 images/ 文件夹），
   禁止凭空虚构任何图片路径；拿不到图片的读图题一律改写为纯文字题或丢弃。
   【图】语义同【材料】：归属其后的题目；进入新分区须重新声明。

R6 质量要求：
   - 答案必须确定无误。任何你不确定答案、或材料中找不到依据的题：丢弃，宁缺毋滥。
   - 讲解必须有实质内容，禁止写"根据原文可知""略"这类空话。
   - 题号在每个分区内从1开始连续编号。
   - 不要加粗题干，不要给题干加编号以外的修饰。
   - 全文使用UTF-8中文常用标点；选项字母必须是大写英文字母A-D加英文句点加一个空格。

═══════════ 输出前自检（逐条核对后再回复） ═══════════
□ 回复以 # 开头，无任何围栏和寒暄
□ 只含单选/多选/判断/填空四种分区
□ 每道选择题恰好4个选项
□ 所有答案行都是加粗的【答案】，判断题只用了√和×
□ 填空线都是6个下划线，多空答案用｜分隔
□ 读图题都用了【图】行且图片文件真实存在；拿不到图片的已改写或丢弃
□ 不确定的题目已全部丢弃
□ 每题都有【讲解】

═══════════ 来源材料 ═══════════
（在此粘贴教材章节/试卷文字/笔记内容）
```

## 二、场景化变体

### 变体A：从教材/PDF章节「收集」题目
在万能模板的 R6 后追加：
```text
R7 补充要求：
- 优先原样保留材料中已有的题目；材料没有题目时，依据本章节知识点出题补足到至少20题。
- 出的新题必须能在材料中找到直接依据，禁止超纲发挥。
```

### 变体B：从试卷照片/截图整理（OCR 场景）
先发图片让AI转录，再清洗。两步法：

第一步提示词：
```text
请逐字转录这张试卷图片上的所有内容，保持原有题号和排版，不要解答，不要遗漏任何小题。图片中模糊无法辨认的字用【?】标注。
```
第二步：把转录文本作为来源材料，套用万能模板（此时 R2 会自动滤掉主观大题）。

### 变体C：让AI原创出题
替换 R6 为：
```text
R6' 出题要求：
- 围绕我给的章节知识点出题，难度分布：基础60%、中等30%、较难10%。
- 干扰项要有迷惑性但必须明确错误；正确选项不得与干扰项含义重叠。
- 总量：单选20题、判断10题、填空10题。
```

### 变体D：清洗已有混乱文档
```text
以下是格式混乱的题库文本。任务：
1. 只提取单选/多选/判断/填空四种客观题，其余题型全部删除。
2. 按 R3~R5 的格式重新排版为标准MD。
3. 发现答案缺失或自相矛盾的题：直接删除该题，不要猜测答案。
4. 输出前执行文末自检清单。
【混乱文本】……
```

### 变体E：错误报告回喂修复（导入被跳过后使用）
App 导入报告会列出被跳过的题。把下面模板+报告内容发回给同一个AI会话：
```text
你刚才输出的文档有部分题目未通过格式校验，以下是校验报告。请重新输出修正后的完整文档（不是补丁），仍然遵守之前的全部铁律。
修复原则：
- W302/W301/W305（缺答案/缺选项/选项残缺）：若能从原始材料找回信息则补全，否则删除该题。
- W310（题号断档）：重排为连续编号。
- W205（主观题混入）：这些分区不需要输出，确认已删除。
【校验报告】
（粘贴App导入报告JSON）
```

## 三、用户操作流程

```
① 复制万能模板 → 贴给AI + 来源材料
        ↓
② AI回复 → 新建 md 文件粘贴保存（UTF-8）
        ↓
③ 人工抽查3~5题答案（AI可能答错内容，格式它不会错）
        ↓
④ 放入科目文件夹 → PC端点击导入
        ↓
⑤ 看导入报告：
   ├─ imported > 0 且 skipped 很少 → 完成 ✅
   └─ skipped 多 / filesRejected → 走变体E回喂修复 → 重导
```

## 四、AI高频坏习惯对照表（提示词条款 ↔ 后果）

| AI坏习惯 | 若流入解析器的后果 | 模板中的对策 |
|----------|--------------------|--------------|
| 用 ``` 包裹整个回复 | G7 把全文当代码块，0题入库(E130) | R1 铁律第一条 |
| 开场白"好的，以下是…" | 游离文本 | R1 + 解析器W314兜底忽略 |
| 主观题舍不得丢，塞进选择区 | 该题无选项被跳过(W301)，污染报告 | R2 明确丢弃指令 |
| `答案：B` / `答案是B` | 无【答案】行→跳题(W302) | R4 规定逐字符格式 |
| 判断题写"对/错/T/F" | 答案非法→跳题(W302) | R4 只许√× |
| 下划线随手打3个或10个 | 能识别但告警(W313) | R4 规定6下划线+解析器容错 |
| 选项写成 `A、xx`（顿号） | 识别不出选项行→跳题(W301) | R4 大写字母+英文句点 |
| 加粗整个题干 `**1. xx**` | 样式C误判风险 | R6 禁止加粗题干 |
| 题号乱跳(1,2,5…) | 自动重排(W310)，无害但脏 | R6 连续编号 + 解析器兜底 |
| 编造没把握的答案 | 内容性错误，解析器拦不住！ | R6 宁缺毋滥 + 流程③人工抽查 |
| 忘记【讲解】 | 保留但空讲解(W312) | R4/R6 要求+自检清单 |
| 一题两个矛盾答案 | 跳题(W307) | 自检清单 |
| 编造不存在的图片路径【图】images/xx.png | 导入告警W323，题目无图可看 | R5a 只引用用户确认存在的图片 |
| 【图】写在分区头之前 | 分区重置，图像被丢弃且无告警 | R5a 【图】必须写在分区内 |

> 注意最后一行加粗提醒：**解析器只能保证"格式正确"，不能保证"答案正确"。**
> 内容正确性靠：提示词R6约束 + 用户人工抽查 + 日常刷题中发现错题时手动标记反馈。

## 五、命名与归档约定

| 项目 | 约定 |
|------|------|
| 文件名 | `第N章_主题_练习.md` 或直接 `练习题.md`（放进章节文件夹） |
| 科目文件夹 | 一个考试科目一个文件夹，如 `英语/`、`毛概/` |
| 章节文件夹 | `01-名词短语/`、`02-定语从句/`（两位序号开头便于排序） |
| 编码 | 保存时选择 UTF-8（Windows记事本默认即是） |
