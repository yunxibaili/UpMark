# 升本通 · 代码生成与审批规范

> 版本: v1.2 | 日期: 2026-08-23（v1.1修订 2026-08-25，v1.2同日修订）
> 地位: 管理性文档，约束本项目**一切代码生成行为**（AI代理或人工）。
> 违反「硬性红线」的代码一律拒绝合入；Gate未通过禁止进入下一阶段。

## 一、代码生成硬性红线（违反即拒）

| 限制项 | 具体要求 | 违反后果 |
|--------|----------|----------|
| **MD解析** | 禁止用 mistune/marked/markdown 等通用库，必须自研行扫描器+状态机 | 通用库会静默吞错，破坏核心 |
| **数据库** | 两端必须用 SQLite，禁止 MySQL/PostgreSQL/MongoDB | 增加部署复杂度，违背"简单不出错" |
| **网络** | 禁止任何公网调用（CDN、第三方API、云存储） | 项目定位纯局域网 |
| **编码** | 文件读写强制 UTF-8 无 BOM，禁止 GBK/UTF-8 with BOM | 解析器会乱码 |
| **错误处理** | 禁止 try-except 静默吞错，必须抛出带上下文异常 | 漏判格式错误 |
| **依赖** | 新增依赖需审批，优先用标准库/已列出的轮子 | 防止依赖膨胀 |
| **GitHub上传** | 禁止上传测试集(test-bank/)、测试脚本(tests/、scripts/)、题库数据(computer-bank/)、DB快照(db_snapshot/)到公开仓库 | 真题内容有版权风险；测试数据含故意缺陷会误导他人 |
| **GitHub上传-版本分支** | 图像支持版本必须与非图像版本**分离上传**：`main` 分支保持无图像版本基线；图像相关实现（解析器【图】/静态图服务/sync v2/App图像渲染等）只存在于 `image-support` 分支，经用户验收批准后方可合入 main | 默认分支混入图像特性，破坏"无图像纯净版"的发布基线 |
| **GitHub上传-归档文档** | `docs/归档/` 内的历史废弃文档一律**不上传**（.gitignore 排除，仅本地保留备查） | 旧规范/旧技术文档流入公开仓库会误导协作者，违反"唯一权威文档"原则 |
| **本地数据** | 以上目录仅存本地，通过 .gitignore 排除；如误推需 force push 重写历史 | 公开仓库历史可翻查，删除提交不够 |
| **并行编辑** | 开工前 `git status` 必须干净并先 pull；同一文件禁止双端同时改（改前在任务清单认领）；完成即提交推送，缩短并行窗口 | 双端同改同一文件会产生重复实现/互相覆盖（T-112实测教训：原子下载写了两层） |

### 1.1 红线落地细则

**错误处理正反例：**
```python
# ❌ 禁止：静默吞错
try:
    parse(line)
except Exception:
    pass

# ✅ 要求：带上下文的显式异常 或 结构化上报（E/W码）
raise FileRejected("E122", lineno, f"代码围栏未闭合于第{lineno}行")
skip_q(q, "W302", f"L{q.line} 缺少【答案】行")     # 跳过也必须留痕上报
```

**编码红线落地：**
- 所有文件读取统一走 `load_source(bytes)`（内建BOM检测→E100）
- 所有写出显式 `open(path, "w", encoding="utf-8", newline="\n")`
- 禁止 `encoding="gbk"` / `locale.getpreferredencoding()`

**当前合规状态**：✅ strict_parser.py 自研712行、零通用MD库、全程E/W留痕。

## 二、接口契约冻结项

> 完整权威版本：《docs/API契约.md》。Agent 2 和 3 必须**严格遵循**，不得擅自修改字段名/类型。

### 2.1 冻结：Question 核心结构

```jsonc
{
  "id": int,
  "type": "single_choice" | "multiple_choice" | "judgment" | "fill_blank",
  "stem": str,
  "options": list[str] | null,      // 判空规则: judge/blank 为 []
  "answer": str,                    // single:"B" multiple:"ABD" judgment:"T"/"F"
  "explanation": str                // 允许空串(W312)
}
```

### 2.2 冻结：同步接口

```
POST /api/sync/progress
Body: [{"question_id": int, "is_correct": bool, "answered_at": str}]
// 可选扩展字段: in_wrong_book, in_favorites （缺省视为false）
```

### 2.3 补充字段（随契约v1一并冻结）

以下字段已在解析器实现并通过测试，一并纳入冻结范围：

```jsonc
{
  "material": str | null,       // 【材料】块原文（阅读理解/完形填空）
  "accepts": [[str]] | null,    // fill_blank专用：每空可接受答案数组
  "global_seq": int,            // 章内重排连续序号
  "source_line": int            // 源文件行号（回溯定位用）
}
```

## 四、代码审查清单（PR必查）

### Agent 1（解析器）

## 五、自动化门禁

> 项目运行时禁公网 ⇒ CI采用**本地一键门禁脚本**为主；
> GitHub Actions 仅作为开发期可选附加（属开发工具，不违反运行时红线）。

```yaml
# .github/workflows/gates.yml （可选；本地等价命令见下）
jobs:
  parser-gate:
    - pytest tests/ --cov=app/parser --cov-fail-under=95
    - python scripts/regression_corpus.py      # 真实题库全量回归
  api-gate:
    - uvicorn app.main:app &
    - curl -f http://localhost:8000/api/sync/all
  app-gate:
    - flutter test
    - flutter build apk --release
```

**本地等价（Windows PowerShell）**：
```powershell
# scripts/run_gates.ps1 （待实现 → 见任务清单 T-107）
python -m pytest tests --cov=app/parser --cov-fail-under=95
python scripts/regression_corpus.py
```
