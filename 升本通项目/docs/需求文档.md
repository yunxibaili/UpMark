## 二、产品定位

1. **类似百词斩的简洁UI学习应用**
2. **学习闭环**: 先学知识点 → 再做题巩固
3. **可扩展科目**: 导入新的MD文件 = 新增/切换一个科目（如未来加英语、高等数学）

## 三、系统架构（已确定）

```
┌──────────────────────┐         ┌──────────────────────┐
│   电脑 (Windows)      │  局域网  │       手机 App        │
│                      │  WiFi   │                      │
│ ① MD文件导入与管理    │ ─HTTP→  │ ① 首次绑定: 输入PC地址 │
│ ② MD解析(全部在此完成) │  JSON   │ ② 科目列表            │
│ ③ 严格格式校验        │         │ ③ 知识点学习(先学)     │
│ ④ 结构化存储(SQLite)  │         │ ④ 刷题练习(后练)       │
│ ⑤ REST API 服务      │         │ ⑤ 即时判分+讲解        │
│ ⑥ 管理后台(可选)      │         │ ⑥ 进度/错题本/收藏     │
└──────────────────────┘         └──────────────────────┘
```

### 架构原则（用户原话提炼）
- "解析md在pc完成" —— 所有MD解析只在PC端进行
- "app绑定对应pc后" —— App首次使用时配置PC的IP:端口
- "pc将解析数据发送到app上，实现显示" —— App只做展示与交互，不做解析
- "程序可以严格规定用户导入md文件内的文字格式" —— 格式白名单制，不符即报错并指出位置
- "这是程序的核心，不能有任何失误" —— MD解析模块必须100%可靠

## 四、功能需求

### 4.1 PC端（服务端）

| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|
| P1 | MD导入 | 选择单个MD文件或整个文件夹批量导入 | 高 |
| P2 | 格式校验 | 导入前逐行校验格式；错误时提示具体文件+行号+原因 | 高 |
| P3 | MD解析 | 按固定语法解析出: 章节树/知识点块/题目(题干/选项/答案/讲解) | 高 |
| P4 | 数据存储 | 解析结果存SQLite；重复导入按章节覆盖更新 | 高 |
| P5 | REST API | 提供科目/章节/知识点/题目/进度上报等接口(JSON) | 高 |
| P6 | 科目管理 | 一个科目=一组MD文件；增删改查科目 | 中 |
| P7 | 管理网页 | 查看题库数量、上传MD、错误报告展示 | 低 |

### 4.2 App端（客户端）

| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|
| A1 | 服务器绑定 | 输入PC的IP:端口, 测试连通, 保存配置 | 高 |
| A2 | 科目首页 | 显示所有科目卡片(C语言/数据结构/自定义), 含进度环 | 高 |
| A3 | 知识点学习 | 按章节浏览渲染后的知识点(表格/代码块/列表), 标记"已学" | 高 |
| A4 | 刷题练习 | 单选/判断/填空; 即时判分; 立刻展开【讲解】 | 高 |
| A5 | 学练衔接 | 学完知识点页尾出现"开始本章练习"入口 | 高 |
| A6 | 进度追踪 | 每章学习状态/答题数/正确率, 上报PC存储 | 中 |
| A7 | 错题本 | 答错自动收录, 可重刷, 答对移除 | 中 |
| A8 | 收藏夹 | 收藏重点题, 集中查看 | 中 |
| A9 | 随机/顺序模式 | 顺序刷题记忆断点; 随机抽题 | 中 |
| A10 | 模拟考试 | 限时组卷(仿广东题型分值), 交卷评分 | 低 |

## 五、非功能性需求

| 类别 | 要求 |
|------|------|
| **可靠性** | MD解析为核心，零容错：任何格式异常必须被拦截并精确定位（文件名+行号+原因），绝不静默吞错 |
| **格式约束** | 只接受规定语法的子集（标题层级/有序题号/A-D选项/【答案】【讲解】标记）；其余Markdown特性仅做展示不支持交互 |
| **网络环境** | 仅限局域网使用，无需公网/账号体系 |
| **性能** | 千题级别秒级加载；App切章无卡顿 |
| **平台** | PC: Windows 10/11；App: Android（iOS可选） |
| **UI风格** | 百词斩式简洁：大卡片、圆角、主色蓝(#4A90D9)、对错绿红反馈 |
| **复用原则** | 优先使用现成开源项目与成熟库，不重复造轮子 |

## 七、MD导入格式规范（已冻结 → 见《MD格式规范v2.0.md》）

**双层防线体系：**
- 第一道：《AI收集题目提示词规范.md》—— 用户用AI收集英语/毛概等任意科目题目时，提示词约束AI输出合规MD
- 第二道：《MD格式规范v2.0.md》—— 解析兜底：坏题自动跳过(W3xx)+上报，分区不支持整区跳过(W205)，绝不静默丢弃

**v2.0 关键结论：**
- **适用任意科目/考试**：基于高考/考研/专升本/成考全题型普查制定；支持单选(含别名"单项选择题")/多选/判断/填空四种客观题
- **新增【材料】块**：支撑阅读理解、完形填空等共享材料成组题
- **题目级容错**：缺答案→跳该题上报；缺讲解→保留空讲解；题号断档→自动重排；只有编码错误/围栏不配对/零有效题才拒整个文件
- 填空多空`｜`分隔、同空多答案`;`分隔（适配英语语法填空）
- 现有计算机题库无需修改即可导入
