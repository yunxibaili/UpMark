## ★ 适用范围（v1.1 核心变更）

本应用面向**任意科目**的刷题学习：计算机、英语、毛概、高等数学……科目仅是文件夹，语法与科目无关。

**仅支持三种客观题型：**

| 支持题型 | 自动判分方式 |
|----------|--------------|
| 选择题（单选/多选） | 字母精确比对 |
| 判断题 | √/× 比对 |
| 填空题 | 文本比对（忽略首尾空白；`;` 分隔多个可接受答案） |

**简答题、计算题、应用题不再支持。**
含这些题型的分区在导入时**整区跳过**（记入导入报告 W205），不影响同文件其他分区入库——现有计算机题库的选择/判断/填空题目全部照常导入。

## 一、全局规则

| 编号 | 规则 |
|------|------|
| G1 | 编码必须为 **UTF-8 无 BOM** |
| G2 | 换行符接受 LF 或 CRLF（解析前归一化为 LF） |
| G3 | 一个 `.md` 文件只允许包含**一个章节**或**一份试卷**的内容 |
| G4 | 制表符 Tab 仅允许出现在代码块内部；正文缩进一律用空格 |
| G5 | 行内格式仅支持：粗体 `**x**`、行内代码 `` `x` ``；其余 Markdown 行内语法（斜体/删除线/图片/链接）在题目字段中**禁止**，在知识点正文中忽略不解析 |
| G6 | `<!-- spec: v1 -->` 可选注释出现在文件首行时，声明遵循本规范 v1 |

## 二、文件类型与命名

| 类型 | 文件名（精确匹配） | 内容 | H1 标题要求 |
|------|------------------|------|------------|
| 知识点文件 | `知识点总结.md` | 章节知识讲解 | `# 第N章 名称`（可带后缀 ` 知识点总结`） |
| 练习文件 | `练习题.md` | 分区练习题 | `# 第N章 名称`（可带后缀 ` 练习题`，空格可省略） |
| 试卷文件 | 任意（如 `2021年真题.md`） | 整卷试题 | `# 试卷名`，允许连续两行 H1 |

**章节号 N 规则：**
- 接受阿拉伯数字（`第1章`~`第99章`）或中文数字（`第一章`~`第十章`）
- 同一科目内编号不得重复（校验码 E101）

**目录即科目：**
```
某科目/
├── 01-章节名/
│   ├── 知识点总结.md     ← 可选
│   └── 练习题.md         ← 必选
├── 02-章节名/
│   └── ...
```
- 子目录名任意，导入顺序按名称排序
- 科目至少含 1 个含 `练习题.md` 的子目录（E102）

## 三、词法元素定义

### 3.1 标题层级

| 语法 | 含义 | 备注 |
|------|------|------|
| `# 文本` | 章节/试卷标题 | 每文件最多2个连续 H1（试卷封面用），其余位置出现即错 E103 |
| `## 文本` | **分区头**（练习题）或**模块头**（知识点） | 见第五、四章 |
| `### 文本` | 题目起始（样式B）或小节标题（知识点） | |
| `#### 文本` | 仅限知识点文件内的小小节 | 练习题中出现即错 E104 |

### 3.2 分区头语法（练习题文件）

```
## <中文序号>、<分区类型><可选注记>
```

- 中文序号：`一`~`二十`，必须从`一`开始且逐区递增（E105）；同一序号不得重复
- **分区类型白名单**：
  - **支持题型**（解析入库）：
    `单选题` `多选题` `判断题` `填空题`
  - **跳过题型**（整区跳过不入库，报告记 W205）：
    `简答题` `计算题` `应用题` `计算题/应用题`
  - **上下文分区**（实际题型由内部题目样式决定）：
    `补充练习题`
- **注记**：紧跟在类型后的括号文本，如 `（每题2分，共10分）`、`（新增）`、`（基于全国各省真题高频考点）`
  - 注记整体作为元数据存储，不参与题型判定
  - `补充练习题` 分区的实际题型由其内部题目样式决定（见 6.3）
- **分区类型允许重复出现**（如 `一、单选题` 与 `六、单选题（新增）`），解析器按出现顺序合并同型题目

### 3.3 题干起始（三种合法样式）

| 样式 | 起始语法 | 正则 |
|------|----------|------|
| A 列表式 | 行首 `数字. 空格` | `^(\d{1,3})\. ` |
| B 标题式 | 行首 `### 数字. 空格` | `^### (\d{1,3})\. ` |
| C 标签式 | 行首 `**题目数字**` 可跟 ` [难度：★+]` | `^\*\*题目(\d{1,3})\*\*( \[难度:[★]+\])?$` |

- 区内题号必须从 1 开始且连续递增（E106）
- 同一分区内混用 A/B/C 样式 → E107

### 3.4 选项行

| 形态 | 语法 | 示例 |
|------|------|------|
| 单行一项（推荐） | `字母. 内容`（可有 0~8 个前导空格） | `   A. int *p;` |
| 单行多项 | 多个 `字母. 内容` 以**两个及以上全角空格**`　`分隔 | `A. 1000B　　B. 1024B　　C. 512B` |

- 字母：大写 ASCII，从 `A` 连续递增（E108）
- 单选/多选题选项数必须为 4（A–D）（E109）
- 选项内容不得为空（E110）
- 判断/填空/简答/计算/应用题分区内出现选项行 → E111

### 3.5 答案行与讲解行

**答案行**（两种等价形式，二选一）：

```
形式1（加粗）：  **【答案】值**        ← 值在加粗内
形式2（加粗空体）：**【答案】** 值      ← 值在同一行标记之后
形式3（非加粗）：【答案】值             ← 仅样式C分区内合法
```

**讲解行**：

```
**【讲解】** 讲解内容...    （加粗，推荐）
【讲解】讲解内容...         （非加粗，仅样式C分区内合法）
```

**值的合法性：**

| 题型 | 值规则 |
|------|--------|
| 单选 | 恰好 1 个字符，∈ {A,B,C,D}（E112） |
| 多选 | 1~4 个字符，∈ {A,B,C,D} 且升序无重复（E113） |
| 判断 | 恰好 1 个字符，∈ {√, ×}。Unicode：√=U+221A，×=U+00D7。`对/错/T/F/正确/错误` 一律非法（E114） |
| 填空/简答/计算/应用 | 非空文本；**多行值**：标记行后紧随的内容行均计入答案，直到遇到空行+下一个块级元素（见 3.6） |

- 缺少答案行 → E115；缺少讲解行 → E116（讲解允许为空字符串但不允许缺失该行）
- 一道题出现 ≥2 个答案行 → E117

### 3.6 题目边界判定

一道题目从「题干起始行」开始，到以下任一条件结束：

1. 下一个题干起始行（样式 A/B/C 任一）
2. 下一个分区头 `## `
3. 文件结束

边界内的自由文本按归属处理：
- 题干起始行之后、第一个选项行/答案行之前的内容 → 追加进题干
- `---` 水平分隔线 → 忽略（仅作视觉分隔）
- 代码块 ```` ``` ```` → 完整保留，整块归属当前正在收集的字段（题干或答案）。**代码块围栏内的一切内容不参与词法解析**（G7，防止代码中的 `A.`、`【答案】` 等被误判）

### 3.7 填空位标记

- 填空处固定使用**恰好 6 个半角下划线** `______`（已审计全库 185 处一致）
- 其他长度下划线（≥3）视为合法但记录警告 W201，解析时同样识别为空位
- 题干中空位数应与答案中 `｜` 分隔的空数一致（见 7.3）

## 四、知识点总结.md 结构规范

```markdown
# 第N章 章节名[ 知识点总结]

## 模块名                    ← 0..n 个模块（如"核心概念定义""易错点"）
### 小节标题                 ← 模块内小节
#### （1）小小节             ← 可选更深一层
正文：段落 / - 列表 / 1. 列表 / 表格 / 代码块 / --- 分隔线
```

规则：
- K1: 除 G1~G7 外，知识点文件**不做结构强校验**，按 Markdown 渲染展示即可
- K2: 但 H1 必须存在且符合第2章命名（E118）
- K3: 文件内若出现 `【答案】` 或 `## 白名单外且形如分区的标题`，告警 W202 提示可能放错文件类型
- K4: 渲染支持的元素：标题/段落/有序无序列表(嵌套≤3)/表格/围栏代码块/水平线/粗体/行内代码

## 五、练习题.md 结构规范

```markdown
# 第N章 章节名[ 练习题]

## 一、单选题[（注记）]
<题目 × n>            ← 样式 A/B/C 之一，区内一致

## 二、判断题[（注记）]
...

## 六、补充练习题（基于全国各省真题高频考点）
<题目 × n>            ← 通常为样式C
```

规则：
- E1: 至少 1 个分区（E119）
- E2: 分区头之后、首个题目之前的游离文本 → E120
- E3: 每道题必须能解析出：题干(非空)、答案；讲解行必须存在（内容可空串）
- E4: 文件末尾允许 ≤5 行的尾部说明文字（如 `*本考点汇总…*`），以斜体包裹 `*...*` 时忽略并记 W203

## 六、三种合法题目样式

### 6.1 规范样式（新内容推荐使用）＝样式A

```markdown
1. 以下哪项是C语言的特点？
   A. 面向对象
   B. 可直接访问物理地址
   C. 无需编译
   D. 不区分大小写
**【答案】B**
**【讲解】** C语言是面向过程的语言……
```

### 6.2 兼容样式B（数据结构章节现行格式）

```markdown
### 1. 栈只能用顺序存储结构实现。（）

**【答案】×**
**【讲解】** 栈可以用顺序存储……

---

### 2. 循环队列可以区分队空和队满。（）
...
```
- `---` 分隔线可选；`（）`是判断题惯例记号，不强制

### 6.3 兼容样式C（扩充题库现行格式）

```markdown
**题目1** [难度：★]
以下哪个是正确的指针变量定义？
A. `int *p;`
B. `int p*;`
C. `*int p;`
D. `int &p;`

【答案】A
【讲解】指针定义格式……
```
- `[难度：★]` 可选；★ 数量 1~3；此样式内答案/讲解行使用非加粗形式
- 该样式常出现于 `补充练习题` 分区，此时分区注记提供上下文

### 6.4 真题单行选项形态（样式A变体，合法）

```markdown
12. 栈的特点是（　）
    A. 先进先出　　B. 先进后出　　C. 随机存取　　D. 任意存取
```

### 6.5 其他科目录入示例（语法与科目无关）

**英语·样式A：**
```markdown
1. He ______ to school every day.
   A. go
   B. goes
   C. going
   D. gone
**【答案】B**
**【讲解】** 主语 He 是第三人称单数，一般现在时动词加 -es。
```

**毛概·样式B：**
```markdown
### 3. 毛泽东思想活的灵魂是实事求是、群众路线、独立自主。（）

**【答案】√**
**【讲解】** 实事求是是毛泽东思想的精髓，群众路线是党的根本工作路线，独立自主是中国革命和建设的基本立足点。

---
```

**英语填空·样式A：**
```markdown
1. She has lived here______1990.
**【答案】** since
**【讲解】** 现在完成时 + since + 时间点；for + 时间段。
```

## 七、各题型的字段规则

### 7.1 单选题 / 多选题
必含：题干、4个选项(A–D)、答案(字母)、讲解。

### 7.2 判断题
必含：题干、答案(√/×)、讲解。不得有选项。
题干末尾 `（）` / `（　）` 若存在则展示时剥离。

### 7.3 填空题
- 题干含 ≥1 个 `______`
- 答案多空时分隔符：中文竖线 `｜`（如 `编译｜链接`）；单空直接写
- 同一空的多个可接受答案用半角分号 `;` 分隔（如 `栈顶;表尾`），任一匹配即得分
- 空位数 ≠ 答案分隔段数 → E121（判分按段比对，忽略首尾空白）
- 英语科目填空示例：题干 `He has______(be) to Beijing twice.`，答案 `been`

### 7.4 不支持题型的跳过规则

遇到白名单中「跳过题型」的分区时：

1. 跳过起点：该分区头行
2. 跳过终点：下一个分区头 / 文件结束
3. 区内内容**不做任何词法校验**（其中可能含代码块、图表、任意文字，一律忽略）
4. 导入报告记录：`{section, startLine, endLine, reason: "unsupported-type"}`，码 W205
5. 同文件其余支持分区正常解析入库

> 设计理由：现有计算机题库每章都含简答/计算分区。若整体拒绝会导致大量可用题目无法导入；整区跳过则客观题全部保留、主观题留待纸质复习。

## 八、校验规则清单（错误码）

### 致命错误（阻断整个文件入库）

| 码 | 条件 |
|----|------|
| E100 | 非 UTF-8 / 含 BOM |
| E101 | 章节号重复（科目内）或无法解析 |
| E102 | 科目包内无任何练习题.md |
| E103 | H1 出现在非法位置 / 数量超限 |
| E104 | 练习题文件出现 #### 标题 |
| E105 | 分区序号不连续/重复/不在白名单 |
| E106 | 区内题号不从1开始或不连续 |
| E107 | 同区分混用题目样式 |
| E108 | 选项字母不连续 |
| E109 | 选择题选项数≠4 |
| E110 | 选项内容为空 |
| E111 | 非选择题分区内出现选项行 |
| E112/E113 | 选择题答案值非法 |
| E114 | 判断题答案值非法 |
| E115 | 缺答案行 |
| E116 | 缺讲解行 |
| E117 | 一题多个答案行 |
| E118 | 知识点文件缺合法 H1 |
| E119 | 练习文件无分区 |
| E120 | 分区头后有游离文本 |
| E121 | 填空数与答案段数不符 |
| E122 | 代码块围栏不配对 |

### 警告（可入库，报告提示）

| 码 | 条件 |
|----|------|
| W201 | 非标准长度下划线空位 |
| W202 | 文件疑似类型放错 |
| W203 | 尾部斜体说明被忽略 |
| W204 | 题干超长(>2000字)或讲解超长(>5000字) |
| W205 | 不支持题型分区被整区跳过（简答/计算/应用） |

**失败策略：单文件任一致命错误 → 该文件整体拒绝，其余文件继续处理；报告列出该文件全部错误行。**
